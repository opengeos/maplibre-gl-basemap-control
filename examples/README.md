# Examples

Example applications for `maplibre-gl-basemap-control`.

## Basic Example

Vanilla TypeScript usage with `BasemapControl` added directly to a MapLibre map.

```bash
npm run dev
```

Open http://localhost:5173/examples/basic/

## React Example

React usage with `BasemapControlReact` and `useBasemapState`.

```bash
npm run dev
```

Open http://localhost:5173/examples/react/

## Build

```bash
npm run build:examples
```

The built examples are written to `dist-examples`.
